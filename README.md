PigmentationAtlas2026
This repository contains the R scripts and analysis materials related to the study "PigmentationAtlas: systematic prioritization of causal effector genes across human pigmentation loci through integrative molecular QTL analysis."

Contents
The materials include:

GWAS harmonization and quality control pipelines
Genomic locus construction and annotation
Molecular QTL database building and analysis
Fine-mapping and colocalization analyses
Visualizations and supplementary figures
Each file corresponds to a specific step (S1-S43) in the analysis workflow, detailing the comprehensive data processing performed in the study.

Usage Instructions
Prepare Input Data
Ensure that you have the appropriate GWAS and reference datasets ready. Detailed input specifications are provided within the manuscript and comments inside the scripts.

Run the Pipelines
The scripts are written in R. You need R installed to run them. The files should be executed sequentially, starting from S1.

Process the Results
The pipelines will produce figures and tables that reproduce the results presented in the manuscript.
